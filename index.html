Projects

Voice-Controlled Robotic Vehicle Using Arduino

© Joel Jose Engineering Portfolio

Project Type:
Academic Prototype

Objective:

Designed and developed a voice-controlled robotic vehicle prototype using Arduino. The project demonstrates embedded system fundamentals, Bluetooth communication, motor control, and hardware integration.

Hardware Components:

  • Arduino Uno
  • Bluetooth Module
  • Motor Driver
  • DC Motors
  • Robot Chassis
  • Battery Supply

How It Works:
A smartphone sends voice commands through Bluetooth communication. The Arduino receives and processes the commands, then controls the motor driver to operate the DC motors, allowing the robotic vehicle to move in different directions.

Technologies:
Arduino, Embedded C Programming, Bluetooth Communication, Electronic Circuits

Skills Developed:
Embedded Programming, Circuit Connection, Hardware Testing, Troubleshooting

Project Outcome:
Successfully developed a working prototype demonstrating embedded system design, wireless communication, microcontroller programming, and hardware integration.
